# Nuxt portfolio

[Документация Nuxt](https://nuxt.com/docs/getting-started/introduction).

## Установка

```bash
pnpm install
```

## Разработка

```bash
pnpm dev
```

Открой [http://localhost:3000](http://localhost:3000).

## Сборка

```bash
pnpm build
pnpm preview
```

[Деплой](https://nuxt.com/docs/getting-started/deployment).
